# Clinic Appointment Booker

A simple web app for booking clinic appointments. Patients pick a day and time, book a visit, and can view, change, or cancel it. A front desk view lets staff see and manage the day's bookings.

**Try it:** https://clinic-booker-demo.pages.dev (works on phone and computer, and offline once installed)

## Features
- Pick a date and an open time slot; double-booking is blocked
- Book, view, change, and cancel appointments
- Front desk view for staff to manage the day's bookings
- Works offline as an installable app (PWA)
- Clear messages if browser storage is full or blocked
- Keyboard and screen reader friendly, with light and dark themes

## Tech
- Static site with plain JavaScript ES modules (no framework, no server)
- PWA with a service worker for offline use
- Data saved in the browser with localStorage (demo only, no real patient data)
- 48 automated tests (`node --test`)
